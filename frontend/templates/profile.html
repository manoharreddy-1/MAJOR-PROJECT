About This Project

AI Resume Analyzer is a CSE(AI) major project using Sentence-BERT (all-MiniLM-L6-v2) for semantic resume-job matching via cosine similarity. The system extends the CareerBERT research approach with skill gap analysis, resume improvement, interview preparation, and personalized roadmaps.
