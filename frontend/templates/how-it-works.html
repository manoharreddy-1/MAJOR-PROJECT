How It Works

Deep learning semantic matching powered by Sentence-BERT

Research Foundation

This project is inspired by CareerBERT ("Matching Resumes to ESCO Jobs in a Shared Embedding Space"). We use a pretrained SBERT model (all-MiniLM-L6-v2) — we do NOT claim to have trained this model. Our contribution is the matching algorithm, scoring system, and career preparation extensions.

Pipeline

1. Resume Upload → PyMuPDF text extraction → OCR fallback (Tesseract + OpenCV)

2. Information Extraction → NLP/NER + section parsing → Skill normalization

3. Job Description Analysis → Requirement extraction → User verification

4. SBERT Embeddings → Section-level embeddings (skills, experience, projects, education)

5. Cosine Similarity → Semantic matching between resume and job sections

6. ATS Scoring → Weighted: 45% Semantic + 30% Skills + 15% Experience + 10% Education

7. Skill Gap Analysis → SBERT per-skill matching with configurable thresholds

8. Generative AI → Resume improvement, interview questions, preparation roadmap

SBERT Semantic Matching

Unlike keyword-based ATS, SBERT understands meaning. "Built CNN models using TensorFlow" semantically matches "Knowledge of Deep Learning and Computer Vision" even without exact word overlap.

Transparent Scoring

Every score is calculated from measurable components. No random numbers. Weights and thresholds are configurable in config/settings.py.
